## 수행 결과

- Python **107개 통과**(기존 104개 + 최종 평가 분모·표본 검사 3개), Node 화면 상태 검사 통과.
- 같은 입력을 주입한 노드별 전후 비교와 JSON/CSV 저장. 외부 모델 정확도·속도로 합산하지 않음.
- 실제 MCP와 OpenAI fast/quality 전체 흐름: 단일·재확인·복수 진단 **3건 passed**, 미등록·대상 확인·이름 저장/재질문 4건 확인.
- 실제 OpenAI 호출 **8회**, API 보고 토큰 **7,861개**. 청구액 미확인. 사용자 DB와 별개인 임시 DB에서 실행.
- 실제 브라우저에서 확인 대화, 오류 주입 부분 실패, 비교·이력·다운로드, 임시 백엔드 재시작 후 복원을 확인.
- 10장 PPT와 발표 대본·결과 보고서·ADR·제출 체크리스트·제출용 ZIP 준비.
- 제출 검사 중 `.env.example`에 실행용 키 값이 들어 있음을 발견해 예제 키 필드를 비웠다. 실제 `.env`는 해시를 대조해 변경하지 않았음을 확인했다. 키 값은 로그·새 문서에 기록하지 않았다. ZIP 생성 전에 차단했다.
- 기존 운영 8100·8600 서버·실행용 `.env`·대화 DB는 재시작/수정하지 않음. Phase 7은 평가 코드·문서 추가이며 제품 기능을 늘리지 않음.
