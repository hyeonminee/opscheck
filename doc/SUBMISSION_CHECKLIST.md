## 시트 복사 문구

[개선사항]

- 조사 대상·계획 검증: 요청한 서비스와 실제 조사 계획을 대조해 누락을 보완하고, 중복·범위 밖 조사를 제외하며 미등록·불명확한 대상은 확인하도록 개선.
- 서비스별 매뉴얼 선택: 각 서비스의 상태·수치·알림을 바탕으로 필요한 복수 매뉴얼을 연결하고 정상·자료 부족을 구분하도록 개선.
- 답변 검증 강화: 서비스·관측 수치·문서 출처·조치 조건을 수집 근거와 대조하고, 재작성 후에도 실패하면 강제 통과 대신 미통과 안내를 제공.
- 조회 실패·시간 초과 대응: 일부 MCP 조회 실패 시 성공 결과를 유지하고, 재시도·처리 시간·생성량에 한도를 두며 오류와 진단 한계를 안내.
- 대화 유지·후속 질문 연결: 같은 대화의 이력과 조사 대상을 보존하고, 대상 확인 답변·재확인 요청을 이전 맥락과 연결해 새로 조사하도록 개선.

[추가 기능]

- 근거 보고서: 관측값·분석·권장 조치·미확인 사항·출처로 진단 결과를 구성하고 검증 상태 표시.
- 조사 이력 저장·조회: 조사별 시각·대상·원형 근거·최종 보고서를 저장하고 같은 대화에서 목록·상세 조회.
- 이전·현재 상태 비교: 같은 서비스의 직전 성공 관측과 새 관측의 CPU·메모리 변화량(%p), 상태·알림 변화 및 비교 한계 제공.
- Markdown 보고서 내보내기: 저장된 진단 보고서·출처·검증 상태·비교 결과를 새 조사 없이 파일로 다운로드.
