ZIP을 풀고 doc/README.md를 먼저 읽습니다. `.env.example`을 참고해 본인 설정을 준비합니다. 키가 있는 `.env`, 사용자 session.db, .venv는 포함하지 않았습니다. Python 가상환경과 Ollama 모델은 새 환경에서 준비해야 합니다. 실제 OpenAI 사용 시 비용이 발생합니다.

이번 묶음은 로컬 파일이며 Google Sheet 등록·외부 업로드·Git 저장소 생성·실제 제출을 대신하지 않습니다. 과거 단계 문서의 로컬 증거 링크 중 전체 개발 로그는 ZIP 밖 원본 프로젝트에 남아 있습니다. 최종 평가 증거는 묶음에 포함했습니다.

UI 변경 전 PPT는 그대로 보존했다. PPT 캡처는 과거 기능 검증 장면이고 실제 시연 화면은 새 UI다.

> 위 ZIP 두 개는 `.gitignore`(`/submission/*.zip`)로 저장소에서 제외되어 GitHub에서는 열리지 않고 로컬에만 있습니다. 이 묶음은 Phase 7 시점이라 최신 코드(Python 130개)와 일부 파일이 다릅니다. 대조 결과는 [최종 평가 검증 보고서](../doc/FINAL_EVALUATION_20261022_084843.md)의 5.3절에 있습니다.
